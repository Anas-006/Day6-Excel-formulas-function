# Task 6 - Excel Formulas & Functions Fundamentals

## Overview
This project demonstrates the use of common Excel formulas and functions on the Sample Superstore transactional dataset.

## Objective
To build practical fluency in everyday Excel formulas used in data analyst work.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset
- GitHub

## Functions Demonstrated
- VLOOKUP
- XLOOKUP (not available in the current Excel version; equivalent lookup demonstrated using VLOOKUP)
- IF
- SUMIFS
- COUNTIFS
- LEFT
- RIGHT
- LEN
- TRIM

## Project Work
The workbook contains:
- Lookup examples using Order ID
- Sales classification using IF
- Conditional sales calculation using SUMIFS
- Order counting using COUNTIFS
- Text manipulation using LEFT, RIGHT, LEN and TRIM
- Blank-cell and number/text edge-case testing
- Short notes explaining when each formula is used

## Outcome
The project improved practical understanding of Excel formulas used for lookup, conditional logic, aggregation, counting, and text cleaning in data analysis.
